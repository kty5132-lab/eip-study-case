# 정처기 학습 (정보처리기사 필기·실기)

개인용 모바일 학습 앱입니다. 설치·로그인·서버가 필요 없고, 학습 기록은 **내 기기(브라우저)** 에만 저장됩니다.
순수 HTML/CSS/JS(PWA)라서 빌드 과정이 없습니다.

## 기능

| 구분 | 내용 |
|---|---|
| 필기 | 영역별 연습(즉시 채점·해설), **모의고사**(타이머·과목별 점수·과락 판정), 오답노트, 북마크 |
| 실기 | 단답/코드 결과/SQL/서술형. 입력한 답을 **자동 채점**(공백·대소문자·구두점 무시)하고 최종 맞음/틀림은 직접 선택 |
| 복습 | 간격 반복(Leitner): 틀리면 바로, 맞히면 1→3→7→14→30일 뒤 다시 출제 |
| 통계 | 영역별 정답률, 최근 14일 풀이량, 모의고사 기록, D-day, 하루 목표 |
| 기타 | 다크모드, 오프라인 동작, 백업/복원(JSON), 내 문제 추가 |

문제 은행: 필기 161문항, 실기 155문항(직접 작성한 학습용 문제). 코드 출력·계산 문제는 실제로 실행해 정답을 검증했습니다.

## 시험 기준

설정에서 **~2026년(5과목·100문항·150분)** / **2027년~(4과목·80문항·120분)** 을 바꿀 수 있고, 모의고사 구성이 따라서 바뀝니다.
합격 기준은 필기 *과목당 40점 이상 + 평균 60점 이상*, 실기 *60점 이상* 입니다.
2027년 개편 내용은 교재·강의 자료 기준이므로, 응시 전에 [Q-Net](https://www.q-net.or.kr) 공고로 꼭 확인하세요.

## 휴대폰에서 쓰는 방법

앱은 정적 파일이라 어떤 정적 호스팅에든 올리면 됩니다. GitHub Pages 예시:

1. 저장소 **Settings → Pages → Build and deployment**
2. Source: *Deploy from a branch*, 브랜치 선택, 폴더 `/ (root)`
3. 잠시 후 `https://<사용자>.github.io/<저장소>/eip-study/` 로 접속
4. 홈 화면에 추가
   - iPhone: Safari 공유 버튼 → *홈 화면에 추가*
   - Android: Chrome 메뉴 → *앱 설치* / *홈 화면에 추가*

> 비공개 저장소의 Pages는 유료 플랜이 필요합니다. 그 경우 Netlify/Cloudflare Pages 등 다른 정적 호스팅을 쓰세요.
> 로컬 확인: `cd eip-study && python3 -m http.server 8000` 후 `http://localhost:8000`

⚠️ 학습 기록은 브라우저 저장소에 있으므로, **브라우저 데이터를 지우거나 기기를 바꾸기 전에** 설정 → 백업·복원에서 백업하세요. (홈 화면에 설치한 앱과 일반 브라우저 탭은 저장소가 따로일 수 있어요. 한 쪽만 쓰는 것을 권장합니다.)

## 문제 추가하기

**방법 1 — 앱에서 입력**: 설정 → 문제 추가·관리 (필기/실기 폼). 기출문제를 풀다 틀린 것을 바로 넣기 좋습니다.

**방법 2 — JSON 가져오기**: 설정 → 백업·복원 → 문제 JSON 가져오기. 같은 문제는 중복 추가되지 않습니다.

```json
[
  { "kind": "w", "area": "db", "q": "문제 내용", "c": ["보기1", "보기2", "보기3", "보기4"], "a": 2, "e": "해설", "code": "(선택) 코드" },
  { "kind": "p", "area": "sql", "type": "term", "q": "문제 내용", "ans": ["정답", "허용하는 다른 표현"], "e": "해설" }
]
```

- 필기 `area`: `design` `dev` `ds` `db` `lang` `basic` `method` `sys` / `a`는 1부터 시작하는 정답 번호(보기 2~5개)
- 실기 `area`: `se` `test` `db` `sql` `os` `sec` `code` `algo` / `type`: `term`(단답) `code`(결과값) `sql`(SQL) `desc`(서술형, `ans`는 빈 배열 가능, 해설이 모범답안)

**방법 3 — 기본 문제 파일 수정**: `data/written.js`, `data/practical.js`.
기록은 `영역-순번`으로 저장되므로 **각 영역 배열의 맨 뒤에만** 추가하세요. 수정 후 검증: `node tools/validate.js`

## 구조

```
eip-study/
├─ index.html · style.css · app.js     앱 본체 (라우터·퀴즈 엔진·복습·통계·설정)
├─ data/written.js · practical.js      문제 은행
├─ sw.js · manifest.webmanifest        오프라인/설치(PWA)
├─ icons/                              앱 아이콘
└─ tools/validate.js                   문제 데이터 검증 스크립트
```

필기 영역과 과목 대응(시험 기준 설정에 따라 모의고사 과목이 달라짐):

| 영역 | ~2026 | 2027~ |
|---|---|---|
| design | 소프트웨어 설계 | 소프트웨어 개발 |
| dev | 소프트웨어 개발 | 소프트웨어 개발 |
| ds(자료구조) | 소프트웨어 개발 | 프로그래밍 언어 활용 |
| db | 데이터베이스 구축 | 데이터베이스 구축 |
| lang · basic(OS·네트워크) | 프로그래밍 언어 활용 | 프로그래밍 언어 활용 |
| method(개발 방법론) | 정보시스템 구축관리 | 소프트웨어 개발 |
| sys | 정보시스템 구축관리 | 정보시스템 구축관리 |

## 알아둘 점

- 보기 순서는 문제별로 고정된 무작위 순서로 섞여 있어, 정답 번호 패턴으로 찍을 수 없습니다.
- 수정 후 반영이 늦으면(서비스워커 캐시) 앱을 한 번 닫았다 열거나 새로고침을 두 번 하세요.
- 문제 은행은 학습 보조용 시작 세트입니다. 실제 기출문제는 저작권이 있으므로 본인이 가진 자료를 직접 추가해 쓰세요.
